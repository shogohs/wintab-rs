# wintab-rs

macOS向けの、ウィンドウ単位で切り替えるCommand+Tabアプリです。同じアプリの複数ウィンドウも、ウィンドウタイトルを見ながら選べます。

## 権限の設定

初回起動時に「アクセシビリティ」と「入力監視」の許可を求めます。両方を「システム設定」>「プライバシーとセキュリティ」で許可すると切り替えが有効になります。許可後はメニューバーの `WT` メニューから「権限状態を再確認」を選んでください。

メニューバーの `WT` メニューでは、アプリの有効・一時停止、権限状態の確認、プライバシー設定を開く操作、終了ができます。

## 使い方

- `Command+Tab` を押すと、アプリのアイコンが横並びで表示されます。最初に前回使ったウィンドウが選択されます。
- `Tab` または左右矢印キーで選択を移動します。
- アイコンにポインターを合わせると選択され、クリックで確定できます。選択中のウィンドウタイトルはパネル下部に表示されます。
- `Command` キーを離すと選択したウィンドウに切り替わります。

診断コマンドや権限トラブルの詳しい手順は[診断ガイド](docs/diagnostics.md)を参照してください。
